## Design Context

### Users
Launchpoint partners and developers evaluating the Public API. They need to understand the product quickly, inspect live campaign data, and prove that each endpoint works without exposing an API key.

### Brand Personality
Confident, sharp, energetic. The interface should feel like a polished partner demo with the honesty and depth of a developer tool.

### Aesthetic Direction
A warm editorial control room: cream canvas, near-black plum navigation, Launchpoint violet, oversized serif moments, and dense but calm data views. Light-first, responsive, and intentionally unlike a generic admin template.

### Design Principles
- Lead with live outcomes, then reveal raw API detail on demand.
- Keep the API key on the server and make side effects explicit.
- Treat broken and empty states as useful product information.
- Use varied scale and spacing to separate signals from supporting data.
- Keep every feature usable on both desktop and mobile.
